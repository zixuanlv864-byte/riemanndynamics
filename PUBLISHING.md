# Riemann website upload set

Upload the six HTML pages, `styles.css`, `script.js`, and the `public/assets/` directory.

The repository intentionally excludes local screenshots, `.DS_Store` files, design-note `.docx` files, and the original 142MB Riemann hero `.mov`. The compressed hero video is `public/assets/riemann-1.0/rm1-top.mp4` (about 54MB) and is selected by `script.js` when the Riemann page loads.

Pages:

- `index.html`
- `company.html`
- `news.html`
- `news-blogs.html`
- `careers.html`
- `riemann-1.0.html`

Before the first commit, check the ignored files with:

```bash
git status --short --ignored
```
